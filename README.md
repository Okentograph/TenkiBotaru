# 天気螢 ― 一年の天気の軌道

8つの都市の一年の天気（2000〜2024年）を、暗闇を巡る光の軌道として描く作品です。

## 始め方

`index.html` をブラウザ（Chrome など）で開くだけです。インターネット接続もインストールも要りません。

## 見方

- 1本の光の輪が、ある都市の一年です。12月31日の次は1月1日へつながっています。
- 位置：横＝日照時間、縦＝気温、奥行き＝降水量
- 色＝気温（寒い 青 → 紫 → 赤 暑い）、線の太さ＝降水量、明るさ＝日照時間
- 画面はゆっくり自動で回り続けます。

## 遊び方

画面の上に都市名、下に年が並んでいます。どちらも同じ操作で選べます。

| したいこと | パソコン | スマホ |
| --- | --- | --- |
| 1つだけ選ぶ | クリック | タップ |
| 足す・外す | Shift＋クリック | 長押し |
| まとめて選ぶ | ドラッグ | なぞる |

都市や年を変えると、光の粒が1秒かけて新しい軌道へ移ります。

パソコンでは、次のキー操作もできます。

- マウスホイール：近づく・離れる
- ← →：年を1年ずつ動かす
- スペース：一時停止・再開
- S：今の画面をPNG画像で保存

## 遊び方の例

- 東京とヤクーツクを並べて、軌道の形の違いを見る
- 東京の2000年と2024年を重ねて、軌道がどれだけずれたかを見る
- 年をなぞって25年分を重ね、その都市の「平均の形」を浮かび上がらせる

## ファイル

- `index.html`・`styles.css`・`script.js`：作品の本体
- `data.js`：都市の一覧
- `weather-data.js`：Open-Meteo から取得した天気データ
